# Yvonne Wu｜Web Developer Portfolio

這是一份用於接案與求職展示的個人作品集網站，主打前端頁面、ASP.NET Web Forms、SQL Server、Firebase 與管理系統開發能力。

## 網站內容

- 個人介紹
- 技能整理
- 專案作品展示
- 可接案服務
- 聯絡資訊

## 使用技術

- HTML5
- CSS3
- RWD 響應式設計
- GitHub Pages 可部署

## 作品集定位

我是一位資訊管理背景的網頁工程師，具備前端頁面、資料管理頁面、ASP.NET Web Forms、SQL 查詢與 Firebase 專案經驗。擅長將需求整理成清楚、好用、可維護的網頁系統。

## 可承接項目

- 小型形象網站
- 個人作品集網站
- 後台管理系統頁面
- 表單與 CRUD 功能
- SQL 資料查詢與報表頁
- 系統流程圖與文件整理

## 如何啟動

直接開啟 `index.html` 即可查看網站。

## 部署到 GitHub Pages

1. 建立 GitHub Repository
2. 上傳 `index.html` 與 `style.css`
3. 到 Settings → Pages
4. Source 選擇 main branch
5. 儲存後即可取得作品集網址
