# Admin Dashboard

這是一個使用 HTML、CSS、JavaScript 製作的管理後台 Demo，可直接部署到 GitHub Pages 或以瀏覽器開啟 `index.html`。

## 功能

- 響應式後台版面，包含側邊選單、統計卡、資料表與右側工作區
- 會員搜尋、狀態篩選與欄位排序
- 新增、編輯、刪除會員資料
- 自動更新營收、活躍會員與待處理訂單統計
- 訂單追蹤、近期活動紀錄與操作提示
- 匯出目前篩選結果到瀏覽器 Console

## 技術

- HTML5
- CSS3 Grid / Flexbox
- Vanilla JavaScript
- RWD 響應式設計

## 使用方式

直接開啟 `index.html` 即可瀏覽與操作。

## 可延伸方向

- 串接 REST API 或 Firebase
- 加入登入權限與角色管理
- 將資料表改為分頁或無限捲動
- 增加圖表視覺化與 CSV 下載
