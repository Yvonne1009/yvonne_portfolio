# login-system

會員登入系統前端展示作品，使用 HTML、CSS、JavaScript 與 LocalStorage 模擬會員資料。

## 功能

- 登入與註冊分頁
- Email、姓名、密碼欄位驗證
- 密碼強度提示與顯示/隱藏密碼
- 記住登入狀態
- 登入後會員中心
- 會員姓名更新
- RWD 響應式版面

## Demo 帳號

- Email: `demo@mail.com`
- 密碼: `123456`

## 使用方式

直接開啟 `index.html` 即可操作。
