# Todo List 任務清單

這是一個使用原生 HTML、CSS、JavaScript 製作的任務管理工具，主要練習 DOM 操作、事件監聽、表單處理、狀態更新與 LocalStorage 本地資料保存。

## 功能特色

- 新增任務並選擇優先順序
- 將任務標示為完成或未完成
- 編輯既有任務內容
- 刪除單一任務
- 篩選全部、未完成、已完成任務
- 一鍵清除已完成任務
- 顯示任務總數與未完成數量
- 使用 LocalStorage 保存資料，重新整理後仍保留任務
- RWD 版面，支援桌機與手機瀏覽

## 使用技術

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 專案重點

這個專案沒有使用框架，目標是透過原生 JavaScript 熟悉前端互動的基本流程：讀取使用者輸入、建立資料物件、更新畫面、處理使用者操作，並將資料保存到瀏覽器本地端。
